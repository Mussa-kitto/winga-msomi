Mipangilio zaidi

Jinsi ya kupata token (mara moja tu)
  1. Ingia GitHub, fungua Fine-grained token mpya.
  2. Token name: Winga Msomi Admin. Expiration: chagua muda (mf. siku 90).
  3. Repository access: Only select repositories → winga-msomi.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Bonyeza Generate token, nakili token, kisha ibandike hapo juu.

Token inakaa kwenye kifaa hiki tu na inatumika kuongea na GitHub peke yake. Ukipoteza simu, ifute kwenye GitHub (Settings → Developer settings → Personal access tokens).
